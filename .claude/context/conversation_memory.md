## Lessons

- _Thing that bit us — how to avoid it._
- 2026-10-28: onglet Clipboard dans l'encoche — sondage de `changeCount` toutes les 0,5 s, 50 éléments gardés dans `Application Support/whoa-stash/Clipboard/` (JSON + PNG, pas `UserDefaults`), contenus `ConcealedType`/`TransientType` ignorés ; un fichier quelconque n'a pas de filtre propre (visible sous « All Clips » seulement), vidéo en orange.
- 2026-10-28: jeton Claude lu via `/usr/bin/security find-generic-password -w` et non `SecItemCopyMatching` — Claude Code réécrit l'item avec `add-generic-password -U` à chaque rafraîchissement, ce qui ramène la liste de partitions à `apple-tool:` et efface le `teamid:` de « Toujours autoriser » ; une lecture directe redemandait donc le mot de passe à presque chaque lancement.
- 2026-10-29: balayage d'onglets de l'encoche (trackpad à deux doigts et glisser souris) via `TabSwipeTracker` ; l'onglet suit le doigt puis change au relâché au-delà de 60 pt, sans rebouclage ; les vues qui défilent (semaine, presse-papiers) gardent leurs événements, la molette de souris est ignorée. Pas de réordonnancement des onglets.
- 2026-10-29: dock personnalisé (`Features/Dock`) — un seul `NSPanel` créé une fois, redimensionné ; épingles copiées une fois de `persistent-apps` (jamais écrit) ; Dock macOS masqué par `autohide` + `autohide-delay` 1000 avec sauvegarde des valeurs d'origine (clé absente = supprimée à la restauration), restauré à la désactivation et à la sortie ; boutons crayon/bulle et pastille « Building » = emplacements, espaces de travail non faits.
- 2026-10-29: espaces de travail du dock (`DockWorkspace` : nom, symbole SF, couleur, applis) ; « Building » amorcé une fois depuis les épingles ; le dock n'est affiché que quand le Dock macOS est masqué (cadre Accessibilité du processus Dock) ; fond = `OverlayPalette.base.panelBackground` comme l'encoche ; raccourci via un second `GlobalShortcutService.dock`.
- 2026-10-29: groupe de gauche du dock = un rond par espace (l'actif en pastille avec son nom), « All Apps » retiré ; sélecteur d'applis façon Launchpad (pastilles de catégories de `LSApplicationCategoryType`) ; survol : `acceptsMouseMovedEvents` obligatoire sur le panneau, curseur et degré d'agrandissement lissés par `CADisplayLink`.
- 2026-10-29: menu radial (`Features/RadialMenu`) ouvert par un bouton « autre » de la souris maintenu (milieu par défaut) via `CGEventTap` actif (`MouseButtonHoldService`, Accessibilité, retente toutes les 2 s) plutôt qu'un raccourci clavier — choix de l'utilisateur ; désactivé par défaut car le bouton est avalé ; visée relative à l'ancre (curseur à l'appui), pas au centre du disque recalé aux bords ; appui bref = menu laissé ouvert (clic, Échap) ; éléments = applis + raccourcis Raccourcis.app (`shortcuts run`), 12 max.
- 2026-10-29: Dock macOS masqué = veilleur shell détaché (fichier témoin + `kill -0`) qui restaure `autohide`/`autohide-delay` si l'app disparaît sans `applicationWillTerminate` (arrêt Xcode, plantage) ; un arrêt normal supprime le témoin avant de restaurer.
- 2026-10-29: applis ouvertes hors de l'espace actif = dossier à droite du dock (panneau au survol, dans la même fenêtre : réserve de hauteur transparente) ; glisser-déposer dans le dock (réordonner, sortir = retirer, déposer un `.app` du Finder) écrit dans l'espace actif via `DockSettings.placeApp/unpinApp`.
- 2026-10-29: Préférences — un changement d'onglet pendant un fondu laissait l'ancien volet par-dessus (`SettingsWindowController.show`) : le volet courant change tout de suite et les restes sont retirés ; deux docks à l'écran = deux instances de l'app (reste de `--show-radial-menu`), pas un bug du dock.
- 2026-10-30: widgets du dock (`Features/Dock/Widgets`) — un type = un fichier + une ligne dans `DockWidgetRegistry.all` ; positions = indices dans la rangée (applis et widgets mêlés), par espace (`DockWorkspace.widgets`, `DockSettings.widgets` pour « All Apps » ; `visibleWidgets`/`setVisibleWidgets`) et recalculées à chaque dépôt (`DockRow`) ; dépôt refusé à gauche du séparateur (espaces de travail, `DockDropZone`) ; batterie par IOKit (`IOPSNotificationCreateRunLoopSource`), `--battery=<0-100>` pour la simuler ; ajout/retrait par espace choisi dans Préférences ▸ Workspaces (boutons, pas de galerie à glisser) ; déplacer ou sortir un widget se fait au glisser dans le dock.
- 2026-10-30: Dock restore — ne jamais enregistrer comme valeurs d'origine celles que l'app a écrites (Dock déjà masqué par nous) ; on garde des clés absentes (SystemDockService.hide).
- 2026-10-30: onglet AI — hooks Claude Code (`Stop`, `Notification`) installés dans `~/.claude/settings.json` par `ClaudeHookInstaller` (fusion, `.whoa-stash.bak` écrit une seule fois, désinstallation qui réécrit les octets d'origine si le résultat est équivalent) ; le script `whoa-hook` est embarqué en chaîne Swift et copié dans `Application Support/whoa-stash/`, il parle à un socket Unix local (`agent.sock`, 0600, aucun réseau) ; pastille d'encoche `AgentEventPillView` (ailes de 150 pt) ; Claude Desktop = veille optionnelle du bouton Stop par Accessibilité (`AXManualAccessibility`), libellé « Stop… » non vérifié sur l'app réelle ; `--agent-event=stop|notify[,projet]` simule un événement.
- 2026-10-30: île de l'encoche retirée par écran quand une app y est en plein écran (`FullScreenDetector` : fenêtre calque 0 couvrant l'écran, barre de menus absente ; signaux Space/app active, relecture unique à 0,7 s, pas de sondage) ; une demande `needsInput` réaffiche l'île le temps de sa pastille, `finished`/`desktopReply`/pastille Bluetooth sont ignorés tant qu'elle est retirée.
- 2026-10-30: courrier dans l'encoche (`Features/Mail`) — IMAP direct (Network.framework, TLS, `EXAMINE` + `IDLE` + `BODY.PEEK`) derrière le protocole `MailSource`, mot de passe au trousseau (`IMAPCredentialStore`), `MailNotificationCoordinator` dédoublonne par `Message-ID` ; voie voulue par l'utilisateur plutôt que règle Mail ou Graph ; pas d'OAuth (mot de passe ou mot de passe d'application seulement), un seul compte ; ailes de 170 pt (au-delà, la silhouette est bornée à la largeur de la fenêtre ≈ 600 pt et le texte déborde) ; `--mail=sample` simule un message ; Outlook/Graph et règle Mail non faits.
- 2026-10-30: Préférences ▸ Mail — menu de fournisseur (`MailProvider` : iCloud, Gmail, Fastmail, Yahoo, Other) qui préremplit serveur et port (champs verrouillés hors « Other ») et rappelle quel mot de passe saisir ; Outlook.com absent tant qu'il n'y a pas d'OAuth ; le fournisseur est enregistré dans `MailSettings.provider`.
- 2026-10-30: demandes d'agent persistantes — hooks `PermissionRequest` (outil + commande/fichier) et `PreToolUse` sur `AskUserQuestion` (questions + choix) ajoutés à `ClaudeHookInstaller`, plus `PostToolUse`/`PostToolUseFailure`/`UserPromptSubmit`/`SessionEnd` pour lever la demande : aucun hook ne signale la réponse, le premier événement suivant de la même `session_id` fait foi (`AgentPromptStore`). La pastille reste (logo + pastille orange) jusqu'à la levée, le survol ouvre l'onglet AI où `AgentPromptCardView` remplace carte, pastilles et activité. Lecture seule : répondre depuis l'encoche = phase 2. Logo : `NSImage(named: "ClaudeLogo")`, symbole `sparkle` tant que l'asset officiel n'est pas fourni. Les clics sur la pastille repliée ne passent pas (fenêtre `ignoresMouseEvents` repliée) : seul le survol de la zone sensible ouvre.
- 2026-10-30: réponse depuis l'encoche — le hook `PermissionRequest` (qui couvre aussi `AskUserQuestion`) s'exécute EN PARALLÈLE de la boîte du terminal, qui s'ouvre sans l'attendre ; une décision tardive du hook la ferme (« Allowed by PermissionRequest hook »). Le script `whoa-hook` reste donc connecté (perl, `nc` se ferme dès la fin de son entrée) jusqu'à la réponse de l'encoche (Allow/Deny, ou un choix pour une question simple : `updatedInput` = `tool_input` + `answers`), 590 s au plus ; la connexion est gardée par `AgentHookServer` (`reply(to:json:)`), et sa fermeture par Claude Code (réponse dans le terminal, session tuée) lève la demande (`onCancel`). Questions multiples ou à choix multiples : affichage seul. Le hook `PreToolUse` sur `AskUserQuestion` reste pour l'affichage immédiat. Une demande expire après 10 min. Logo : mascotte pixel fournie par l'utilisateur, recréée en SVG (`ClaudeLogo.imageset`).
